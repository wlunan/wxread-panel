# wxread-panel

微信读书自动阅读脚本的**多面板通用版**,适配青龙面板、白虎面板等定时任务平台。
基于 `https://github.com/findmover/wxread` 实现,**仅作为学习使用,不作为其他目的**。

## 支持的面板

脚本不依赖任何特定面板,只要面板**把环境变量注入任务进程**(`os.environ`)即可运行:

| 面板 | 是否支持 | 说明 |
| --- | --- | --- |
| 青龙面板 | ✅ | 另兼容其 `QLAPI` 接口读取作为兜底 |
| 白虎面板 | ✅ | 环境变量在任务执行时自动注入进程 |
| 其它定时面板 / 直接运行 | ✅ | 走系统环境变量或 `config.py` 默认值 |

环境变量读取顺序:`os.getenv` → 青龙 `QLAPI` → 默认值。因此同一份代码在各面板间通用。

## 与主项目的差异

- **不定自带调度**:定时由面板的任务 cron 负责,脚本内不包含调度逻辑(无 `scheduler.py`)
- **环境变量读取**:面板无关(优先 `os.getenv`,回退青龙 `QLAPI`)
- 其余逻辑与主项目一致:目标总时长随机、请求间隔随机、synckey 修复、鉴权错误处理、Cookie 自动刷新等

## 项目介绍 📚

- **阅读时长随机**:设置目标总时长的区间,读够即停,次数自动推导
- **请求间隔随机**:每次请求间隔在区间内随机,节奏更接近真人
- **Cookie 自动更新**:脚本能自动获取并更新 Cookie,一次部署后无需其它操作

## 操作步骤 🛠️

### 抓包准备

在微信读书官网 [微信读书](https://weread.qq.com/) 搜索【三体】点开阅读点击下一页进行抓包,抓到 `read` 接口 `https://weread.qq.com/web/book/read`,如果返回格式正常(如:

```json
{
  "succ": 1,
  "synckey": 564589834
}
```
右键复制为 Bash 格式。

### 通用配置(所有面板)

- **依赖**:安装 Python 依赖 `requests`
- **变量**:按下表配置环境变量
- **定时**:用标准 Cron 表达式,例如 `0 7 * * *`

| key                        | Value                               | 说明                                                         | 属性      |
| ------------------------- | ---------------------------------- | ------------------------------------------------------------ | --------- |
| `WXREAD_CURL_BASH`         | `read` 接口 `curl_bash`数据 | **必填**,必须提供有效指令                                   | 变量/机密 |
| `READ_TIME_MIN` / `READ_TIME_MAX` | 目标总阅读时长范围(分钟) | **推荐**,例如 `20` / `60`,每次运行随机读够 20~60 分钟;想固定就把两项填相同值 | 变量 |
| `READ_INTERVAL_MIN` / `READ_INTERVAL_MAX` | 每次阅读间隔范围(秒) | **可选**,默认 `20` / `40`(均值约 30 秒);该值约等于单次计入的阅读时长,不建议大幅偏离 30 | 变量 |
| `READ_NUM` | 阅读次数(每次 30 秒) | **已弃用(兼容保留)**,仅当未配置 `READ_TIME_*` 时回退,等价于 `READ_NUM × 30 秒` | 变量 |
| `PUSH_METHOD`              | `pushplus`/`wxpusher`/`telegram`/`serverchan` | **可选**,推送方式,4选1,默认不推送 | 变量 |
| `PUSHPLUS_TOKEN`           | PushPlus 的 token                   | 当 `PUSH_METHOD=pushplus` 时必填 | 变量/机密 |
| `WXPUSHER_SPT`             | WxPusher 的 token                   | 当 `PUSH_METHOD=wxpusher` 时必填 | 变量/机密 |
| `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID` | 机器人 token 与群组 id | 当 `PUSH_METHOD=telegram` 时必填 | 变量/机密 |
| `SERVERCHAN_SPT`           | ServerChan 的 SendKey               | 当 `PUSH_METHOD=serverchan` 时必填 | 变量/机密 |

### 青龙面板

#### 一键拉取仓库

在青龙面板的「订阅管理」新建订阅，或进入容器终端后执行以下命令，即可拉取本项目：

```bash
ql repo https://github.com/wlunan/wxread-panel.git "main.py|config.py|push.py|requirements.txt" "" "" "master"
```

> 第 2 个参数是白名单，必须保留 `main.py|config.py|push.py|requirements.txt`，否则部分青龙版本会将空白名单当作“不保留任何文件”。`ql repo` 只负责拉取/更新脚本；首次使用仍需安装 Python 依赖并配置环境变量。订阅管理中可直接将上述整行作为订阅命令，以便后续自动更新。

- 依赖管理 -> Python3 -> 创建依赖 -> 安装 `requests`；或在容器终端进入脚本目录后执行 `pip3 install -r requirements.txt`
- 在「环境变量」里配置上表变量
- 新建定时任务，执行拉取目录中的 `main.py`，并填入 Cron 表达式，例如 `0 7 * * *`

### 白虎面板

- 「依赖管理」中为 Python 安装 `requests`
- 上传/同步本工程脚本
- 在「环境变量 / 机密」里配置上表变量(`WXREAD_CURL_BASH` 等敏感值建议放**机密**,支持 AES-GCM 加密与日志打码)
- 新建定时任务,填入 Cron 表达式

## Attention 📢

1. **只签到**:只需签到完成挑战赛,可将目标阅读时长设短,例如把 `READ_TIME_MIN`/`READ_TIME_MAX` 都设为 `1`(即 1 分钟)。

2. **解决阅读时间问题**:对于 issue 中提出的“阅读时间没有增加”,“增加时间与刷的时间不对等”建议保留 `config.py` 中的【data】字段,默认阅读三体,其它书籍自行测试。

3. **书籍随机**:与主项目一致,脚本每轮会从 `config.py` 的 `book`/`chapter` 列表中随机取书与章节;如担心影响时长累计,可自行将 `main.py` 中对应的两行改为固定值。
